# How To Set Up

- clone this repository
- cd into directory
- npm install (or npm ci) to install dependencies
- rename .env.example to .env and enter your information and credentials
- get SQL DDL and DML from this repo https://github.com/maddin-damago/kalender_project_sql_und_doku
- follow instructions from the SQL repo to setup your database and fill it with data
- run "npm start" to start the nodemon server
